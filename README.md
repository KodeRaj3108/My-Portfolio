# K PRUTHVI RAJ – Personal Portfolio Website

A minimalist, HTML-only personal portfolio website showcasing my skills, experience, and projects.  
This site is designed to be a central hub for my professional presence and a clean, recruiter-friendly profile.

## Live Demo

Once deployed via GitHub Pages, the site will be available at:

- `https://KodeRaj3108.github.io/My-Portfolio/`

## Features

- Simple, fast, and lightweight HTML-only implementation
- Clean personal brand layout with a hero section
- About section with a concise professional summary
- Skills section highlighting tools, technologies, and domains
- Experience section with role, company, and key contributions
- Projects section with links, tech stack, and outcomes
- Contact section with email and social links
- Fully responsive design for desktop and mobile (via CSS)

## Tech Stack

- **HTML5**
- **CSS3**
- Optional: a small amount of **JavaScript** for interactions (if used)

No frameworks or build tools are required. The site can be opened directly in a browser and easily hosted on GitHub Pages.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/KodeRaj3108/My-Portfolio.git
cd My-Portfolio
```

### Run locally

Since this is a static HTML project, you can simply open `index.html`:

- Double-click `index.html`, or  
- Use a local server (optional):

```bash
# Using Python 3
python -m http.server 8000

# Then open http://localhost:8000 in your browser
```

## Customization

- Update text content in `index.html`:
  - Name, title, and tagline in the hero section
  - About summary
  - Skills list and categories
  - Experience entries (role, company, dates, highlights)
  - Projects (name, description, links, stack)
  - Contact information and social profile URLs
- Customize design in `css/styles.css`:
  - Colors, fonts, spacing, and layout
  - Hover states and transitions
  - Responsive breakpoints for mobile and tablet
- Replace placeholder images in `assets/images` with your own:
  - Profile photo
  - Project screenshots

## Deployment – GitHub Pages

1. **Create and push to the GitHub repository**  
   Your repository is already created as `My-Portfolio`:

   ```bash
   git clone https://github.com/KodeRaj3108/My-Portfolio.git
   # Make changes, then:
   git add .
   git commit -m "Update portfolio content and styles"
   git push origin main
   ```

2. **Enable GitHub Pages**  
   - Go to **Settings** in the `My-Portfolio` repository.
   - Scroll to **Pages**.
   - Under **Source**, select:
     - Branch: `main`  
     - Folder: `/ (root)`  
   - Click **Save**.

3. **Access your live site**  
   - After a short build, GitHub Pages will provide a URL:
     - `https://KodeRaj3108.github.io/My-Portfolio/`
   - Share this link as your live portfolio.
